# Lot Acreage Visualizer

Visualize a single-story home footprint on your parcel, to scale. Adjust lot size, shape, and house square footage to see how much yard space remains.

**Live demo: [jacoblbagent.github.io/lot-acreage-visualizer](https://jacoblbagent.github.io/lot-acreage-visualizer/)**

---

## Features

- Interactive lot & house sizing with real-time canvas rendering
- Adjustable lot shape (wide ↔ tall)
- Adjustable house shape (wide ↔ tall)
- Average-sized structure & item toggles (garage, shed, pool, driveway, etc.)
- Drag to reposition the house on the lot
- Snap-to-grid placement
- Undo / redo support
- Clear all to reset

## Usage

Open `index.html` in any modern browser, or visit the [live demo](https://jacoblbagent.github.io/lot-acreage-visualizer/).

## Files

- `index.html` — HTML structure
- `styles.css` — all styling
- `script.js` — canvas rendering, interaction logic, and state management
